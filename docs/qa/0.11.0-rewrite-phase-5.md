# Frontend rewrite phase 5: design modules · 2026-10-21

Phase 5 of issue #3 moved the canvas artwork into one TypeScript module per design (`src/designs/`) and split the editor's old main module, `exploration-full-logic.js`, into `studio-session.js`, `studio-views.js` and `studio-app.js`, which removed the import cycle between it and the UI modules. Nothing was meant to change on screen or in exports. This record lists the checks beyond the automated suite, including the final comparison that closed the rewrite. Run on macOS (Apple silicon), Node.js 22.19, Docker 29.5.

## Automated suite

After every commit: `node tools/build.mjs` and `node tools/check.mjs` passed (96 unit tests, including the new `designs.test.ts` registry test, plus the `tests/check-*.cjs` scripts). `npm run test:visual` matched all 130 baseline frames after the module split. The saved-state byte counts printed by the checks (the HTML/OBS thirteen-design boundary 20,688 → 12,089 bytes) did not change.

`dist/index.html` went from 2,408,950 to 2,412,395 bytes: the moved code is formatted one statement per line, and the bundle is not minified.

## Canvas operations

A one-off script, not committed, ran the five original scene modules (`exploration-full-scene.js`, `design-language-scene.js`, `urban-language-scene.js`, `dual-language-scene.js`, `studio-geometry.js` at `e277d50`) and the new `src/designs/index.ts` side by side under Node, against a recording canvas that logs every method call and property write, with gradients tracked by identity:

| Cases | What varied | Result |
| --- | --- | --- |
| 2,352 | Every design (plus an unknown key) × 14 geometry styles × 6 patterns × both ratios | Identical |
| 12,000 | Random combinations of every setting: background, swap, transparency, intro progress, clocks, invalid accents and shadow colours, shadow and floor, motion switches, strengths, scales, parallax, dual split and guides; canvas sizes including zero; with and without the AE recorder's intro hooks | Identical |
| 14 | Every key with empty settings | Identical |
| 28 | `designPalette` against `designLanguagePalette`, every key, light and dark | Identical |

127,879,408 recorded operations in all. Changing a single line width in `tuner.ts` made 234 cases differ, so the comparison does detect small changes.

## Module graph

A one-off script walked the frame script's imports from `src/main.js`: 53 modules, no import cycles (type-only imports excluded).

## Editor comparison

The phase 4 differential harness (one-off, not committed; see [0.11.0-rewrite-phase-4.md](0.11.0-rewrite-phase-4.md)) ran the phase 4 build as merged (`e277d50`) and the phase 5 build in the pinned image (`v1.64.1-noble`): layout screenshots, editor markup, all 152 editor controls and 11 output dialog controls changed in order, and HTML, OBS and AE exports. Everything was identical. The AE ZIP is byte-identical; the HTML and its OBS copy are 2,500 bytes larger, the size of the reformatted script.

## Against the pre-rewrite frontend

To close the rewrite, the screenshot suite ran once against a build of `frontend-legacy/` (the frozen pre-rewrite copy, from `b8495e4`) in place of `dist/index.html`. All 130 frames matched the baseline, as the phase 5 build does, so the finished rewrite renders every baseline frame exactly as the original did. With this recorded, `frontend-legacy/` is deleted in the follow-up cleanup change.

## Not checked

- The page on Windows hosts, Safari and Firefox. CI builds and checks on Windows but does not open the page.
