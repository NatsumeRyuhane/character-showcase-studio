# 0.9.0 双镜头片头验证

日期：2026-10-20。

新增「双镜头海报 · 角色 → 作者」。两个独立镜头使用各自的素材、时长、对角文案和叠加效果，然后转入已有展示页。原有模型先行与大字片头保留。边框沿用画布设置并保持独立。

## 自动检查

- 生产时间函数和渲染器：片段边界、任意进度拖动、暂停、四种对角位置、开关镜头、两个镜头全关、减少动态、持续展示和独立圆环时钟。
- 扫描线 / 全息 / 偏振：12 组确定性绘制检查；过渡期间继续播放覆盖层。
- 状态迁移、保存、图片回退、打包过滤、直接展示、1080p / 4K 空间缩放和异常数据拒绝。
- 主展示和旧片头切换时，将整个海报层设为 display:none，防止子层 visibility 覆盖父层隐藏。包含生产渲染器回归。
- 既有十三套构图、环形路径、信息动效、滚动边框、老电视片尾与 HTML / OBS / AE 数据检查保留。

## 实际浏览器

在独立本地测试标签中检查横屏角色镜头、作者镜头、Holo / CRT、竖屏反向对角布局、左右边框，以及跳到主展示后旧海报层完整关闭。控制台未见页面错误。

通过真实输出面板生成并下载横屏 1080p 与 4K AE ZIP：两组片头各含四个可编辑文字图层。逐项比较两份 scene.json，文字坐标、边界和字号精确为两倍；时间不变。独立 4K HTML 也通过实际下载。

上传选择器的自动化事件未在当前预览客户端返回，因此未声称完成真实文件选择 UI 的端到端验证。图片来源回退、隐藏、素材打包和尺寸在生产函数测试中覆盖；测试用几何图片不包含在产品页面。

## 验证范围

本次未启动桌面 AE 逐帧审片。AE 的扫描线、全息光带和偏振色带为可编辑原生近似效果，不逐像素复制网页 Canvas；文字和素材保持分层。桌面未安装的字体可能被 AE 替换。
