# Frontend rewrite phase 3: typed pure logic · 2026-10-21

Phase 3 of issue #3 moved the pure logic into typed TypeScript modules with Vitest unit tests (see [build-and-test.md](../dev/build-and-test.md#unit-tests)): the `tuple-v1` codec, the narrative timeline, the motion clocks, typography settings, the editor state (`src/studio-state.ts`), and the shell's export packaging (now a second Vite bundle, `runtime/output-host.ts`). This record lists the checks beyond the automated suite that show nothing users see or save changed. Run on macOS (Apple silicon), Node.js 22.19, Docker 29.5.

## Automated suite

After every commit: `node tools/build.mjs` and `node tools/check.mjs` passed (77 unit tests at the end, plus the remaining `tests/check-*.cjs` scripts), and `npm run test:visual` matched all 130 baseline frames. The saved-state byte counts printed by the checks (default 8,854 bytes; the HTML/OBS thirteen-design boundary 20,688 → 12,089 bytes) were the same before and after.

## Differential checks

One-off scripts, not committed, ran the code from before each move and the new modules on the same inputs in `node:vm`:

| Area | Inputs | Result |
| --- | --- | --- |
| State restore and save (`exploration-full-logic.js` at `bbb31d4` vs `studio-state.ts`) | Startup preset, visual-test fixture, v1 / v4 / early Studio documents, plus 1,000 randomly corrupted copies of the preset; each restored, saved, then restored again on top | Restored state and saved payload identical as JSON text in every case; no input threw in one version only |
| Export packaging (the four `runtime/*.js` scripts at `dc5bb06` vs the `.ts` modules) | Two AE scenes, HTML and OBS exports in both orientations, 1080p and 4K, combined and three-layer, plus 1,000 randomly corrupted payloads (322 accepted, 706 rejected) | Results, every packaged file and every error message identical; ZIP bytes identical |

The only expected difference: the synchronized OBS layer pages embed `studioOBSLayerBootstrap` by its source text, which the bundle now reprints with different formatting. It is the same code.

## Browser export

In the pinned Playwright image (`v1.64.1-noble`), the built `dist/index.html` was loaded and `studioOutputHost.download` called from the shell for an HTML export, an OBS package (combined, 4K), an OBS package (three layers) and an AE package. All four downloaded with the expected names and contents, with no page errors. The exported HTML opened from disk and rendered its artwork without errors.

## Deliberate changes

Restore now requires strings where a string is meant (hex colours, series, design and geometry keys). Before, values that only became valid after string conversion, such as `['#abcdef']`, were accepted and saved. The editor never produces them. Default design settings no longer share nested objects with the defaults table.

## Not checked

- OBS and After Effects themselves: the packages were not imported into either application.
- Windows hosts, and CI on GitHub (the branch is not pushed yet).
