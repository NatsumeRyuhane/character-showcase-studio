# Frontend rewrite phase 4: React editor · 2026-10-21

Phase 4 of issue #3 rebuilt the editor UI in React (`src/editor/`), panel by panel: output dialog, typography, sequence and post-processing, content pane, inspector, then the header, toolbar and playback controls. It also removed the Codex shell's leftover UI kit (tooltip, tab and carousel scripts, Floating UI, the full Lucide library). The artwork and its paint loop did not change. This record lists the checks beyond the automated suite that show the editor still looks, behaves and saves the same. Run on macOS (Apple silicon), Node.js 22.19, Docker 29.5.

## Automated suite

After every commit: `node tools/build.mjs` and `node tools/check.mjs` passed (93 unit tests at the end, including new jsdom component tests for the panels, plus the `tests/check-*.cjs` scripts). `npm run test:visual` matched all 130 baseline frames after each step that could move the preview: the inspector, the workspace, and the kit removal. A single case was run after the content pane step. The saved-state byte counts printed by the checks (the HTML/OBS thirteen-design boundary 20,688 → 12,089 bytes) did not change.

`dist/index.html` went from 2,614,098 bytes before this phase to 2,408,950 bytes. React is now bundled; the kit's scripts and 600 KB of Lucide are gone.

## Deliberate changes

- The output dialog tabs now use a roving `tabindex` (`0` on the selected tab, `-1` on the other), as the ARIA tabs pattern expects.
- The hidden `<select>` that the old series tabs mirrored into is gone; the series buttons write the setting directly.
- Kit CSS that no element used any more was removed when `runtime/visualize.css` became `runtime/frame.css`.
- Unused "Tweak" code in the logic module was removed.

## Not checked

- OBS and After Effects themselves: the packages were not imported into either application.
- Screen readers, and keyboard-only use beyond the dialog tabs and the Escape shortcuts.
- Windows hosts, Safari and Firefox, and CI on GitHub (the branch is not pushed yet).
