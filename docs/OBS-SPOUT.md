# OBS 只输出页面本体

使用 OBS 浏览器源，不需要窗口捕获或浏览器全屏。源本身就是纯展示画面。

## 专用输出包

0.11.0 起可在「OBS 输出结构」选择一体源或三层源。

三层源使用以下流程：

1. 安装 Node.js 18 或更新版本，完整解压导出包，运行 `START-LAYERS.cmd`。
2. 本机同步服务会生成 `IMPORT-IN-OBS.json` 并打开控制页，再从 OBS 导入该 JSON。
3. OBS 中从下至上为画面、透明光效、边框；可自行插入角色的视频或 Spout 源。开场角色放在光效下方，展示角色放在光效上方。
4. 在控制页确认三个源在线后，统一开始、暂停、重播、跳到展示或进入片尾。某一源重新加载会自动追上公共时间。
5. 服务需要保持运行。重复启动同一包会复用服务；结束时在控制页关闭同步服务。服务重启后使用重新生成的场景文件更新地址。

三层文件需经本机服务打开，不能直接双击各 HTML。透明光效源只能叠加光带、扫描线、波纹、炫光等，无法读取其他 OBS 源像素。真正的扭曲、辉光及色散仍在画面源内部完成；外部角色若需要这类处理，应使用 OBS 自身滤镜或 AE。边框没有启用时，该源输出透明画面。

一体网页仍无需 Node 或同步服务，包内 `output.html` 及原有流程继续可用：

1. 工作台「输出 / AE 模板」→「OBS 纯画面」，选择尺寸、适配方式、透明底、是否含角色图。
2. 下载 OBS 输出包，解压到固定文件夹。
3. 双击 PREPARE-OBS.cmd。它根据当前文件夹生成 IMPORT-IN-OBS.json，只写入导出文件夹，不改 OBS 设置。
4. OBS「场景集合 → 导入」选择这个 JSON，并切换到新集合。
5. OBS「设置 → 视频」将基础画布设为导出窗口标出的尺寸。导入场景集合不会可靠地修改全局视频配置。

横屏：1920×1080 / 3840×2160。竖屏：1080×1920 / 2160×3840。源与画布宽高比应一致。

## 手动添加

OBS 添加「浏览器」源 → 本地文件 → output.html，宽高设为输出尺寸，帧率 60。已有源有缩放或位移时，右键「变换 → 重置变换」，再「适配屏幕」。

- 完整显示：保留全部构图，宽高比不同时可能留边。
- 铺满裁切：填满源的视口，超出部分裁掉；最好直接选择与画布一致的横竖屏。
- 透明底：背景不填色，保留文字、几何、边框等，便于叠加 Warudo 角色画面。

所有资源打包进 HTML，保留沙盒 iframe 与 CSP，编辑面板不进入画面。修改工作台后需重新导出并刷新 OBS 源。

源右键「交互」后可用快捷键：空格暂停 / 继续，R 重播片头，S 直接展示。

## Spout2

网页本身不能直接充当原生 Spout2 发送端。若需要将此纯画面送给其他 Windows 软件，在 OBS 安装官方来源的 obs-spout2-plugin，为浏览器源添加 Spout Filter 并命名发送端，再到接收软件选择它。

本次没有安装插件或改动正在运行的 OBS 配置；Spout2 收发链路仍需实际联调。

官方资料：

- https://obsproject.com/kb/browser-source
- https://github.com/Off-World-Live/obs-spout2-plugin

## 片头与片尾

关闭品牌片尾后，可选择「持续展示 · 不回到起点」（默认）或「按时长循环 · 重播展示入场」。持续展示只播放一次片头和信息入场，随后所有动效持续运行，不在设定时长处重置；空格暂停后继续保持当前画面。展示时长在此模式中只决定 AE 导出长度和编辑器进度预览范围。修改模式后重新导出 HTML / OBS 包，旧文件不会自动更新。

「片头、展示与片尾」设置会随独立 HTML / OBS 包保存。展示时长可设 1–60 秒。R 重播片头，S 进入展示；启用品牌片尾后 E 可随时结束展示并进入片尾。手动模式保持展示循环，自动模式在设定时长后进入。片尾可停在品牌画面，也可开启赛博关机，在最后一段收成亮线与光点后停在黑场；边框持续显示。关机包含在片尾时长内。空格可暂停 / 继续，停在末尾时再次播放会从片头开始。快捷键需先打开 OBS 浏览器源的「交互」。
