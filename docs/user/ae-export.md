# 可编辑 AE 模板导出

顶部「输出 / AE 模板」→「AE 可编辑模板」。选择输出尺寸、帧率、透明底、是否包含片头及角色图。先点击「生成 AE 模板」，完成后再点击「下载 AE 模板」。两次点击让较大素材有充分准备时间，同时保留沙盒下载的用户操作边界。

## 在 AE 打开

1. 完整解压 ZIP，保持 `IMPORT_TO_AE.jsx` 与 `assets/` 相邻。
2. After Effects「文件 → 脚本 → 运行脚本文件」，选择 `IMPORT_TO_AE.jsx`。
3. 脚本向当前项目添加独立文件夹、主合成、几何、背景图案和边框合成，不关闭或重置已有项目。
4. 打开 `01 MAIN`，在 `CONTROLS` 调颜色、标识底色、几何速度、文字动效及过渡时间。展开其他合成可以编辑路径关键帧、文字及素材。
5. 使用 AE 的另存为，保存 `.aep`。

浏览器输出的是生成工程的脚本和素材包。原生 `.aep` 工程由本机 AE 创建。

网页 / OBS 的「持续展示」可以无限播放；AE 导出仍使用「导出展示时长」生成有限长度的可编辑合成，不会尝试生成无限关键帧。片头与片尾长度继续单独计算。

## 可编辑性

### 0.10.0 图层顺序与替换素材

`01 MAIN` 从上至下保留：控制器 → 独立边框 → 展示角色 `MODEL · ABOVE FX` → 光效 `FX OPTICS` → 调整层 `FX ADJUSTMENT` → 片头 / 片尾 → 展示文字 → 几何 / 图案 / 背景。

- 展示角色与特写放在绿色 `MODEL` 素材容器内，位于两层 FX 上方，不受这组后处理影响。
- 开场角色和作者素材放入 `INTRO CHARACTER / CREATOR` 内的绿色 `REPLACE` 容器，字幕与素材一起经过 FX。
- 即使没有上传图片，也会生成空素材容器；引导文字为 guide layer，不进入最终渲染。
- 图层编号、标签颜色、注释以及 `EDIT / REPLACE / DESIGN / FX / ASSETS` 文件夹帮助定位。文字、角色、光效与边框均可单独改动。

`CONTROLS` 中的 `Post FX Strength / Glow / Speed / Fade` 调整后处理强度、辉光、连续动态速度、淡入淡出时长；`Post FX Character / Author / Showcase / Ending` 选择镜头。滤镜始终使用合成绝对时间，相邻启用镜头之间不会重启。时间控制跟随可编辑镜头与片尾开始设置。网页里的文字自定义会收集为可编辑的 AE 文本、字号、字距、斜体、字重与颜色；桌面仍需有对应字体。

AE 后处理由内置效果与原生形状近似实现，不烘焙整段画面。光效预合成可继续编辑扫描线、光带、波纹及炫光；调整层可直接增删效果。更换整套后处理方案可在网页重选后导出。网页的 SVG 扭曲、棱镜与材质不会逐像素还原。旧模板需要重新导出才能获得新结构。

| 要素 | AE 形式 |
| --- | --- |
| 角色名、系列、说明、格式与署名 | 原生文字图层 |
| 标题切形与色块 | 原生形状图层 |
| 圆环、主几何和装饰 | 原生贝塞尔路径，按运动变化自适应加密关键帧 |
| 文字进入与轻微动态 | 表达式；Text Motion 控制强度 |
| 背景格线、圆点与波纹 | 独立原生形状合成，近似网页图案 |
| 上下 / 左右边框 | 独立合成、可编辑文字、滚动表达式 |
| 标识 | 原生底板与文字；图形是独立 PNG |
| Logo / 二维码 / 条码 / 角色图片 | 独立素材及容器合成 |
| 投影 | 标题使用原生 Drop Shadow；其他复杂投影需在 AE 继续调节 |
| 后处理 | 独立调整层与原生光效预合成；可移动层序及关闭 |

## 片头与品牌片尾

模型先行与原版大字片头均保留：前者让模型先显示，角色名按所选时间淡入，其余信息在展示页出现。关闭「包含引入页动画」后直接从展示开始。

「双镜头海报」片头增加独立的 `07 INTRO CHARACTER` 与 `08 INTRO CREATOR` 预合成；只为已启用的镜头创建合成。角色名、系列、编号、说明及作者署名均是独立原生文字图层。角色图 / 作者图是可替换素材，页面中的缩放与位置会随逻辑画幅一起导出。上传的 WebP 会先转换为 PNG，并同时更新镜头里的素材引用。

前两幕保留独立边框，主展示的圆环、图案、角色图及信息从海报到展示的转场开始时出现。镜头切换保持海报式的直接剪切；最后一幕与展示交叉淡化。可选的切换闪光为独立 `STORY · optional cut flash` 原生图层，默认不生成。

在 `CONTROLS` 调整以下控件：

| 控件 | 用途 |
| --- | --- |
| `Character Shot Start / Duration` | 角色海报镜头的开始与停留时长 |
| `Author Shot Start / Duration` | 作者海报镜头的开始与停留时长 |
| `Post FX Strength / Glow` | 统一后处理的强度与辉光 |
| `Post FX Speed / Fade` | 连续动态速度与镜头边界的淡入淡出时间 |

两幕的开始时间可以独立修改。调整一幕时长后，如果希望两幕连续衔接，应同步设置下一幕的开始时间。`Show Transition Start` 与 `Information Start` 会跟随最晚结束的镜头，同时保留滑杆本身输入值相对于初始安排的偏移；因此仍可以直接提前或推迟转入展示。`Show Transition Duration` 控制最后海报与展示的淡化长度，圆环旋转继续使用独立时钟。

「只输出包装」会保留海报文字与效果而省略两幕图片；导出选项关闭「包含角色图片」也会省略镜头图片。不存在素材时保留文字和空白舞台，不生成角色。透明输出保留透明背景。故事预合成和素材容器沿用主合成总长度，便于在已有范围内调整时间；延长整段视频仍需同步延长相关合成与图层。

新版海报使用 MAIN 中统一的后处理叠层；旧数据中独立的镜头轻效果仍可兼容导入。CRT、全息、偏振、泛光、炫光、棱镜及胶片以原生效果与形状近似，不会把海报烘焙成一张图。未选择特效时 FX 不参与渲染。

启用片尾时增加 `06 ENDING` 品牌合成与 ENDING 时间标记。品牌字样是可编辑文字；Logo 是可替换素材。收束线条、轨道与小几何均为原生形状，入场由表达式驱动。片头、展示、片尾的长度会一起按播放速度换算。

0.8.7 将关机改为老电视式收束：轻微栅格闪烁，画面纵向压成亮线，亮线向中央收缩，最后留下短暂的荧光亮点再归黑。主合成中的 `SHUTDOWN` 上下遮片、闪光、扫描线、亮线及光晕、中央亮点及余晖均可单独编辑。`Cyber Shutdown` 控制开关，`Shutdown Duration` 控制最后一段关机时长（换算后的合成秒数）；不增加片尾长度，最长仍为导出片尾时长的 45%。关机锚定主合成末端，边框始终位于这些图层上方。关闭关机会停在品牌落版。

## 在 AE 调整过渡

选择 `01 MAIN` 中的 `CONTROLS`，在效果控件面板修改以下滑杆。时间单位都是当前 AE 合成的秒数，已经包含网页播放速度的换算。

| 控件 | 用途 |
| --- | --- |
| `Show Transition Start` | 圆环从片头位置移向展示位置的开始时间；原版大字片头的名字位移和缩放也跟随此控件 |
| `Show Transition Duration` | 上述移动和大小过渡所用时间；持续旋转速度保持独立 |
| `Information Start` | 「模型先行」模式的信息出现时间，默认等于片头结束时间；角色名选择展示时出现时也从此处淡入 |
| `Information Fade Duration` | 信息淡入时长；原版大字片头仍保持依次入场，淡入长度可单独调整 |
| `Title Fade Duration` | 「模型先行」模式角色名的淡入时长；延后显示的名字保留与信息出现时间之间的原有提前量 |
| `Ending Start` | 展示内容退场、品牌片尾开始的时间，默认等于展示段末端 |
| `Ending Transition Duration` | 展示到品牌片尾的交叉淡化及品牌元素入场总时长 |
| `Geometry Speed` | 持续几何运动的速度；设为 0 时圆环停止旋转，仍可进行位置与大小过渡 |

例如，把 `Show Transition Duration` 从 3.6 改为 1.2，圆环会更快落到展示位置，环内持续旋转不被加速。希望信息再晚一秒出现时，单独把 `Information Start` 增加一秒；希望更早进入品牌落版时，把 `Ending Start` 提前。

`INTRO / SHOWCASE / ENDING / CYBER SHUTDOWN` 时间标记仅标注导出时的初始安排，拖动标记不会改变表达式时间。请使用上述滑杆设置过渡。没有导出片头时，圆环已位于展示位置；默认从第一帧显示信息，仍可用 `Information Start` 延后信息入场。

修改这些控件不会自动增减主合成、预合成或素材图层的总时长。结束时间受当前合成长度约束。需要增加整段片长时，建议先在网页设置片头、展示和片尾时长再导出；在 AE 手动延长时，还需同步延长相关预合成及图层。调整 `Ending Start` 时也应给末端关机留出所需时间。

## 效果边界

0.8.4 修复了快速旋转圆环在两帧路径之间异常缩小的问题。导出器会检查区间内的真实曲线，将变动较大的路径单独加密，AE 中明确使用线性关键帧，同时记录变化的描边宽度。原有片头的移动和大小过渡继续保留。静止路径只保留必要的边界关键帧。更密的运动数据可能让生成、导入和保存花更长时间。

已经生成的 ZIP / AE 工程不会自动更新。请使用新版工作台重新生成模板，并在 AE 导入新的文件夹；保留旧工程中的自定义修改后，再替换相应几何合成。

- 金属、云雾、毛绒渐变转为近似纯色矢量形状；细密纤维只保留主形状。
- CSS 滤镜、动态毛玻璃、颗粒、暗角、路径裁切和虚线不逐像素映射。需要保留网页原效果时使用 OBS / HTML 输出。
- 桌面缺少对应字体时 AE 会替代，中文使用微软雅黑。网页的 WOFF2 字体不能视为已经安装到系统的桌面字体。
- 文字可以继续编辑；改成长短差异很大的内容后，需要在 AE 重新调整位置或缩放。
- 合成长度为所选片头时长加自定义的 1–60 秒展示段，再加已启用的片尾，并按当前整体播放速度换算。手动触发只影响网页 / OBS，AE 始终生成完整有限段落。长时间连续输出仍推荐 OBS 浏览器源。
- 代码与生成包检查不能代替对每种设计、字体、效果组合的 AE 人工审片。

## 开发入口

- src/ae-canvas-recorder.js：将生产绘图器的 Canvas 路径记录为贝塞尔顶点。
- src/ae-geometry-motion.js：比较路径顶点、控制点、透明度与描边宽度，按误差细分关键帧；后台标签页也可完成导出。
- src/ae-export.js：按导出尺寸测量当前布局、提取文字和独立素材、采样几何。
- runtime/export-packages.js：校验沙盒传来的纯数据、生成 ZIP 文件清单。
- runtime/ae-import-template.jsx：可信 ExtendScript 模板，用原生 AE API 创建合成。
- runtime/crt-motion.js：网页与 AE 共用的确定性老电视关机包络；构建时注入两端。
- runtime/export-zip.js：无依赖 ZIP writer。
- tests/check-export-packages.cjs：生产几何、数据边界、脚本语法、OBS 场景和 ZIP 校验。
- tests/check-ae-geometry-motion.cjs：旋转圆环半径、28 组生产几何、片头过渡、中间帧误差与静止段检查。实际 AE 核对记录见 `../qa/0.8.4-ring-motion.md`。

所有脚本来自本地可信模板；参数以 JSON 数据字面量写入，不接受用户传入可执行表达式、脚本正文或任意素材路径。
