# 工作台使用说明

本文说明编辑器的各个区域及常用功能。导出到 OBS 与 After Effects 的具体步骤见 [obs.md](obs.md) 与 [ae-export.md](ae-export.md)。

## 界面布局

页面分为三栏：

- **左侧「作品内容」**：顶部的「系列管理」可切换 ATELIER、FUR、MINI 三个系列，并展开修改各自的系列名称、编号和中英短句。下方依次编辑角色与品牌、上传图片、交付格式、适配标识、作品链接和条码。
- **中央「画面预览」**：顶部选择视觉方案、横竖画幅及信息边框；下方是预览画面和播放控制（播放、片头、展示页、左右互换、时间轴、播放速度）。「专注预览」可放大画面，按 Esc 返回。
- **右侧「画面样式」**：按配色与字体、圆环与几何、动态背景、文字动效、标识外观、阴影和滤镜分组调整。启用信息边框后会出现边框文字与滚动设置；双画面方案会显示分区设置。

窗口宽度小于 1120 像素时，三栏改为「作品内容 / 画面预览 / 画面样式」三个页签，默认打开预览。

## 设置的保存范围

- **随系列保存**：系列名称、编号及短句。
- **随视觉方案保存**：配色、字体和各种效果。几何样式可以按「视觉方案 × 系列」分别选择。
- **所有方案共用**：角色名字、素材、交付格式、适配标识等。

文字和设计参数保存在当前浏览器中，刷新后仍然保留。

> **注意：上传的图片不会保存。** 角色图、补充图、片头角色镜头图、片头作者镜头图、Logo、二维码及条码图片只在当前打开的页面中有效，刷新后需要重新选择。交接时请另外提供原始素材。
>
> 设置按网页地址分别保存：本机预览（`start.cmd`）与线上网址的设置互不相通。

## 视觉方案

共 13 套视觉方案，在中央顶部的选择器中分为「原有方案」和「街头二游 · 新增」两组。每套方案分别保存自己的默认值和调整。

街头二游的三套方案把信息集中在约三分之一的画面中，其余空间留给角色：

- **街区 · 超频档案**：斜切字标、分段机械环与街头档案细节，默认深底酸绿，适合高对比、有态度的角色。
- **映像 · 午夜频道**：录像带式字标、调频轨道及少量信号刻度，默认暖浅底配橙色，节奏更疏朗。
- **潮玩 · 弹性街角**：圆体字标、异形玩具环与错位切形，默认浅底蓝色，轻快但保留展示留白。

这三套借鉴现代都市二游的视觉语言，几何与字体排版均为原创，不包含《绝区零》的官方 Logo、角色或界面素材。几何选择「此构图的推荐设计」时使用方案专属的圆环，也可以换成其他通用几何。

**双画面方案**（「酸绿贴纸 · 双画面排版」）可调分区比例 35%–60%，支持画面指引、左右互换及竖屏。主角色图和补充角色图分别用于两个展示区域。

## 画幅、边框与标识

- 横屏 16:9 或竖屏 9:16，可左右 / 上下互换信息与角色的位置。
- 信息边框可选上下或左右，能编辑边框文字，并分别设置两条边框的滚动方向和速度。边框从片头到片尾始终显示。
- 适配标识（MMD、ARKit、VRCFT、lilToon、Poiyomi 等）提供多种样式，可调整底色、图形与文字颜色和透明度。这些标识只是展示内容，选择它们不代表模型已完成对应适配，请与实际交付内容保持一致。

## 文字排版

「文字排版」集中调整角色名的字体、字号比例、字距、字重、斜体与颜色，也可以单独填写开场镜头的标题和引导小字；不修改时沿用设计原样。短句也可以调整字级和字距。

这些设置随项目保存，并会带入网页输出和 AE 模板的可编辑文字层。

## 片头、展示与片尾

左侧的「片头、展示与片尾」区域统一管理整段动画，所有方案和横竖屏共用这组设置。

### 片头

- **双镜头海报**（新项目默认）：先展示角色镜头，再展示作者镜头，然后进入展示页。前两幕只显示对角文案，隐藏展示页的信息和圆环。两个镜头可以分别关闭，各自设置 0.5–12 秒时长、图片缩放和位置；镜头间过渡 0.15–3 秒。默认总长为 2.5 + 2 + 0.6 = 5.1 秒。
  - 角色镜头图与作者镜头图分别上传，支持 12 MB 以内的 PNG、WebP、JPG。没有上传专用镜头图时，会使用已有的角色图片；完全没有图片时只保留文字。
  - 「只显示包装」会隐藏镜头图片；切换闪光为可选项。
- **模型先行**：开场隐藏角色名、说明与标识，角色和圆环从一开始就可见。角色名可以在展示页淡入，或在片头后段浮现（可调延迟百分比）。
- **大字开场**：原版的大字缩回信息区的过渡。
- 模型先行与大字开场的片头长度可设 0–30 秒，设为 0 秒即跳过片头。双镜头片头的长度由各镜头和过渡自动计算。

时间按 1× 播放速度计算，调整播放速度会改变实际时长。圆环使用独立的连续时钟，不会因重播或切换而跳动。已有项目原来选择的「模型先行 / 大字开场」会保留，不会被新的默认片头覆盖。

### 展示

- **展示时长**：1–60 秒，可以输入小数。修改时长会保留当前段落的相对进度。
- **无片尾时的播放方式**：
  - 「持续展示 · 不回到起点」（默认）：片头只播一次，信息入场后一直保持展示，圆环、背景、文字和边框持续运动；暂停后继续也不会重播。此时展示时长只决定 AE 导出的长度和进度条范围。
  - 「按时长循环 · 重播展示入场」：每到展示时长就重新播放展示入场。

### 品牌片尾

- 独立开关，时长 1.5–12 秒。有签名落版、轨道回声、安静留白三种动画，可以使用品牌字样或上传的品牌 Logo；没有 Logo 时自动使用字样。
- **触发方式**：展示到设定时长后自动进入，或保持展示、手动点击「片尾」进入。片尾结束后再次播放会从头开始。
- **老电视关机**（默认开启）：短促闪动与扫描纹理后，画面压成横向亮线，再缩成中心光点，最后余辉消失到黑场。时长 0.3–1.5 秒，最多占片尾的 45%，包含在片尾时长内。边框持续显示。

品牌文字和 Logo 取自左侧「角色与品牌」。

## 画面后处理

「画面后处理」提供偏振流光、CRT、全息、柔光、横向炫光、棱镜色散和胶片光漏。可以分别勾选作用于角色镜头、作者镜头、展示页、片尾，并调整强度、辉光、动态速度和淡入淡出。两幕字幕都支持居中。

后处理按素材用途分层：

- 开场两幕的素材与字幕位于后处理**下方**，会被一起处理。
- 展示页的角色图及特写位于后处理**上方**，不受影响；背景和文字会被处理。
- 边框始终独立，不受后处理影响。

AE 模板同样保留独立的后处理调整层和光效层，可在 AE 中自行调整层序。AE 中的效果是近似实现，外观不会与网页逐像素一致。

## 输出

顶部「输出 / AE 模板」提供两类输出：

- **OBS 纯画面**：下载独立 HTML 或完整 OBS 输出包，支持横竖屏、1080p / 4K、透明底、是否包含角色图、完整显示 / 铺满裁切。OBS 输出可选一体网页源或三层网页源（画面、透明光效、边框）。详见 [obs.md](obs.md)。
- **AE 可编辑模板**：下载 ZIP，在 After Effects 中运行包内的 `IMPORT_TO_AE.jsx`，生成可编辑的文字、形状、圆环路径、图案和滚动边框，再另存为 .aep。详见 [ae-export.md](ae-export.md)。

几点通用说明：

- 输出文件是导出时的快照。修改设计后需要重新导出，旧文件不会自动更新。
- 1080p 与 4K 使用同一套排版，4K 只提高分辨率，各元素在画面中的比例不变。
- 独立 HTML 会从片头开始自动播放角色镜头、作者镜头、展示和已启用的片尾。导出的画面不受系统「减少动态效果」设置影响；编辑器仍会遵守该设置。
- 输出页快捷键：空格暂停 / 继续，R 重播片头，S 跳到展示，E 进入片尾（需先开启片尾）。在 OBS 中使用快捷键前，需要先打开浏览器源的「交互」。

## 字体

本地包已内置 5 个拉丁字体家族（Barlow Condensed、Cormorant Garamond、Manrope、Nunito、Space Grotesk），无需联网。中文使用电脑上的微软雅黑、苹方或其他系统字体，因此换电脑后中文字形和换行可能略有差异。
