# AE 圆环运动检查 · 0.8.4

检查日期：2026-10-19。

## 问题与修复

旧导出每 0.5 秒记录整条路径。路径上的对应顶点在 AE 中走直线，快速旋转时经过圆弧内侧，造成周期性收缩。刚性半径 400 像素的回归用例在旧插值中缩小约 95.8 像素。

新版逐区间比较真实运动，单独加密偏差较大的路径，并明确设置线性插值。同步记录描边宽度，防止片头几何缩回时线条留在另一尺度。原始设计的轻微浮动和片头尺寸过渡仍然保留。

## 自动回归

- 刚性旋转圆环半径的最大误差约 0.101 逻辑像素。
- 28 组生产绘图器组合：10 套方案、其余经典 / 系列几何、竖屏与互换，使用 3× 圆环速度及 1.8× 整体速度；共 8304 次捕获。独立检查的中间帧最大偏差约 0.317 逻辑像素。
- 覆盖片头至展示过渡、静止区间首尾、空场景、后台导出让出事件循环、拓扑不一致显式失败。
- 原有片头 / 展示 / 片尾、独立边框、状态迁移、4K 等比、素材与导出边界测试均通过。新增描边采样的缩放、合法范围与旧数据兼容检查。

运行方式：先 `node tools/build.mjs`，再 `node tools/check.mjs`。

## 浏览器与 AE 实测

通过独立 localhost 页面实际操作导出，不刷新用户原来打开的文件页。After Effects 2026 在独立实例导入，用户原有工程不受影响。

横屏样本使用「斜切宣言 / 交错轨道」，1920×1080，30 fps，3× 圆环速度、1.8× 整体速度、2 秒片头 / 6 秒展示 / 4 秒片尾（未按速度换算前）。包含上下独立边框和赛博关机。

- 核对 17 个时刻的 187 条原生路径，包括非关键帧时刻和片头边界。
- 顶点、切线与描边对生产绘图器的最大误差为 0.2201 输出像素。
- 检查所有路径关键帧的 LINEAR 类型、表达式、四个独立边框图层及关机亮线。
- 实际渲染连续三帧，工程保存为 `verified.aep`，结果为 `RING CHECKS OK`。

竖屏样本使用「时尚 · 留白刊物 / 推荐金属环」，2160×3840，30 fps，使用相同速度与时长，含左右独立边框。

- 核对 17 个时刻的 170 条原生路径，最大误差为 0.4523 输出像素（约 0.2262 逻辑像素，包含约 0.02 输出像素的 CSS 子像素取整差异）。
- 实际浏览器包内有 4508 组路径采样，单组最多 665 个；压缩空白后的场景 JSON 约 20.3 MB，完整 ZIP 正常下载并通过 CRC 检查。
- 检查关键帧插值、描边、表达式、独立边框及关机图层；实际渲染三张连续 4K 帧并保存工程，结果为 `RING CHECKS OK`。

开发机验证材料位于交接目录同级的 `outputs/ring-motion-qa/horizontal/` 与 `vertical-4k/`，含实际导出脚本、场景数据、原生工程、渲染帧及检查结果。验证器为同级 `work/verify-native-rings.cjs`。

较密集的数据增加了 AE 导入时间。场景数据改为无缩进 JSON，避免仅排版空白就使文件超过 ZIP 条目限制；48 MiB 原始场景数据限制仍保留。

## 更新旧工程

需要用新版页面重新生成 ZIP 并重新导入。旧工程不会自动改变。导入产生独立文件夹，可保留原工程，对照替换几何合成或重新应用原有修改。
