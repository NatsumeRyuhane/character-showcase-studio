# 角色展示设计工作台

这是可编辑、可本地运行的站点源码包，当前版本为 0.11.0，包含 13 套视觉方案（含「酸绿贴纸 · 双画面排版」及三套街头二游方向），并提供独立的双镜头海报片头。页面采用三栏编辑器，适合自己调节展示画面，或交给其他设计师和前端开发者继续修改。

## 0.11.0 OBS 三层输出

在「输出 / AE 模板 → OBS 纯画面 → 输出结构」选择三层网页源，可分别获得画面、透明光效、边框三个源。原来的一体网页和单独 HTML 仍保留。

三层包需要 Node.js 18 或更新版本。完整解压后运行 `START-LAYERS.cmd`，它会启动本机同步服务、生成 `IMPORT-IN-OBS.json` 并打开控制页。导入 OBS 后，从控制页统一播放、暂停、重播、跳至展示或进入片尾。三源共用绝对时间，单独刷新某层后会追上其他层。服务只监听本机；一体版不需要此服务。

OBS 从下到上的顺序为画面 → 光效 → 边框；外部角色源可自行插入，展示时放在光效上方即可保持干净。独立光效源提供扫描线、波纹、光漏和炫光，无法读取别的 OBS 源的像素。真正的辉光、色散、扭曲仍在画面源内处理；需要处理外部角色时使用 OBS 自身滤镜或 AE 调整层。

## 0.10.0 文字与分层后处理

「文字排版」集中调整角色名的字体、字号比例、字距、字重、斜体与颜色，并可单独填写开场镜头的标题和引导小字；默认沿用原设计。短句也可调整字级和字距。设置会随项目保存，并带入网页输出及可编辑 AE 文字层。

「画面后处理」提供偏振流光、CRT、全息、柔光、横向炫光、棱镜色散和胶片光漏。可分别勾选角色镜头、作者镜头、展示页、片尾，并调整强度、辉光、动态速度和淡入淡出。两幕字幕都支持居中。

后处理分层按素材用途区分：开场两幕的素材与字幕位于后处理下方；展示页角色及特写位于后处理上方，背景和文字接受处理。边框始终独立。AE 工程同样保留独立后处理调整层、原生光效层、素材替换容器及编号文件夹；可在 AE 自行移动层序。AE 后处理采用内置效果和原生形状近似，外观不与网页逐像素一致。已有旧模板需重新导出。

## 立即查看

**直接打开根目录的 `index.html`。** 页面已构建完成，预览不需要安装依赖，也不需要登录账号。建议使用较新的 Chrome 或 Edge。

如浏览器限制直接打开本地文件，或者需要更稳定地记住设置：

1. 双击 Windows 下的 `start.cmd`。
2. 保持弹出的终端窗口开启。
3. 在浏览器打开 `http://127.0.0.1:8768/`。

启动脚本优先使用 Node.js 18 或更新版本，找不到时使用 Python 3。也可以自行在此文件夹启动任意静态网页服务器。端口被占用时，运行 `node tools/server.mjs 8769` 后访问对应端口。

## 使用要点

- **左侧「作品内容」**：在独立的「系列管理」区域选择 ATELIER、FUR、MINI，并展开修改各自的系列名称、编号和中英短句。下方集中编辑角色与品牌、上传图片、交付格式、适配标识、作品链接和条码。
- **中央「画面预览」**：顶部选择 13 套视觉方案、横竖画幅及信息边框；下方预览画面并控制播放、片头、展示页、左右互换、时间轴和播放速度。可使用「专注预览」扩大画面，按 Esc 返回。
- **右侧「画面样式」**：按配色与字体、圆环与几何、动态背景、文字动效、标识外观、阴影和滤镜分组调整。选择信息边框后，右侧会出现边框文字与滚动设置；双画面方案会显示分区设置。
- 窗口宽度小于 1120 像素时，改用「作品内容 / 画面预览 / 画面样式」三个页签，默认打开预览。
- 「系列」和「视觉方案」分别选择：系列名称、编号及短句随系列保存；配色、字体和效果随视觉方案保存；几何样式可按「视觉方案 × 系列」分别选择。角色名字、素材、格式与标识等在所有方案之间共用。
- 新增双画面方案支持分区比例 35%–60%、可选画面指引、左右互换及竖屏。主角色图和补充角色图用于两个展示区域。
- 可选择横向或竖向边框，编辑边框文字，并分别设置两条边框的滚动方向和速度。
- 圆环大小、动画速度、片头播放、时间轴、文字动效、背景动效、投影颜色及各层开关均保留。
- 提供多种标识样式，可自行调整底色、图形文字颜色和透明度。
- 页面在当前浏览器中记住文字和设计参数。**上传的角色图、补充图、片头角色镜头图、片头作者镜头图、Logo、二维码及条码图片只在当前打开的页面内有效，刷新后需重新选择。** 交接时请另行提供原始素材。

本地包已内置界面运行时、图标、条码/二维码库和 5 个拉丁字体家族。无需联网加载这些资源。中文使用电脑上的微软雅黑、苹方或其他系统无衬线字体，换电脑时字形及换行可能略有差异。

## 0.8.8 街头二游方案

中央「视觉方案」选择器新增独立的「街头二游 · 新增」分组，原有十套方案仍在「原有方案」中。三套新方案采用不同的文字排版、配色及推荐几何，信息集中在约三分之一画面，其余空间留给角色：

- **街区 · 超频档案**：斜切字标、分段机械环与街头档案细节，默认深底酸绿，适合高对比、有态度的角色。
- **映像 · 午夜频道**：录像带式字标、调频轨道及少量信号刻度，默认暖浅底配橙色，节奏更疏朗。
- **潮玩 · 弹性街角**：圆体字标、异形玩具环与错位切形，默认浅底蓝色，轻快但保留展示留白。

这些是借鉴现代都市二游视觉语言的原创几何与字体排版，不包含《绝区零》的官方 Logo、角色或界面资产。三个方案分别保存自己的默认值及后续调整，沿用横竖屏、信息互换、边框、圆环大小与速度、动态背景、可选适配标识、投影、片头片尾及 OBS / AE 导出。选择「此构图的推荐设计」使用专属环形，也可切换到原有几何方案。

## 片头、展示与品牌片尾

左侧独立的「片头、展示与片尾」区域统一管理：

- **双镜头海报片头**：新项目默认从片头开始。先展示角色镜头，再展示作者镜头，随后进入原有展示页；前两幕隐藏主展示页的信息和圆环，只保留对角文案轻入场。角色与作者镜头可分别关闭、设置 0.5–12 秒时长、调整图片缩放及位置；两组镜头时长与 0.15–3 秒过渡共同决定总片头长度，初始为 2.5 + 2 + 0.6 = 5.1 秒。
- **独立镜头素材**：角色镜头图与作者镜头图分别上传，支持 12 MB 以内的 PNG、WebP、JPG。未上传专用镜头图时，会使用已有的角色图片；没有图片时保留文字包装。在「画面后处理」统一选择滤镜与作用镜头，独立调整强度、辉光、速度及淡入淡出；「只显示包装」隐藏镜头图片，闪光为可选项。镜头设置随项目保存，上传图片仅在当前会话与包含素材的导出包内有效。
- **模型先行**：开场隐藏角色名、说明与标识，角色和圆环从开始就可见。角色名可在展示页淡入，或设为片头后段浮现，并调整延迟百分比；不会从画面中心放大冲出。
- **大字开场**：保留原版的大字缩回信息区的过渡。
- **引入页时长**：模型先行与大字开场可设 0–30 秒；0 秒跳过片头。双镜头片头由各镜头与过渡设置自动计算时长，关闭两幕即直接展示。时间按 1× 播放计算，速度会影响实际时长。圆环使用独立连续时钟。
- **无片尾时的播放方式**：默认「持续展示 · 不回到起点」。片头只播一次，信息入场后保持展示，圆环、背景、文字和边框一直运动，暂停后继续也不会重播。也可选择「按时长循环 · 重播展示入场」。此设置会保存在独立 HTML / OBS 输出包中。
- **展示时长**：1–60 秒，可输入小数。持续展示时，此处是 AE 导出的展示长度及进度预览范围，不会限制网页 / OBS 的播放；按时长循环时为每轮时长，启用自动片尾时为进入片尾前的展示长度。更改长度会保留当前段落的相对进度。
- **品牌片尾**：独立开关，时长 1.5–12 秒。签名落版 / 轨道回声 / 安静留白三种小动画，可用品牌字样或上传的品牌 Logo。缺少 Logo 时自动退回字样。
- **触发方式**：展示到设定时长后自动进入，或保持展示循环、手动点击「片尾」进入。片尾结束后再次播放会从头重播。关闭片尾时使用所选的持续展示 / 按时长循环模式。
- **老电视关机**：默认开启，可关闭。短促闪动与扫描纹理后，品牌画面压成横向亮线；亮线向中心缩成光点，余辉衰减至黑场。边框持续显示。关机时长 0.3–1.5 秒，最多占片尾的 45%，包含在片尾内。AE 中的遮罩、亮线、光晕与光点均可独立编辑。

品牌文字和 Logo 沿用「角色与品牌」，所有方案和横竖屏共用这组叙事设置。

已有项目的「模型先行 / 大字开场」选择会保留，不会被新默认片头覆盖。独立 HTML / OBS 若选择「直接展示」，会跳过双镜头片头；取消「包含角色预览图片」会同时排除主角色、补充角色及两张片头镜头图。「只显示包装」也不会将片头镜头图打包出去。AE 导出将角色与作者镜头拆为独立海报预合成，可编辑各自的图片、文案与简化特效，并在主控制器分别调整镜头开始时间、时长及特效强度和速度。

从 0.8.7 起，导出的 AE 工程在 `01 MAIN → CONTROLS` 提供独立的转场开始时间和时长：`Show Transition Start / Duration` 控制圆环与标题移位，`Information Start / Fade Duration` 控制信息淡入，`Title Fade Duration` 控制名字淡入，`Ending Start / Transition Duration` 控制展示转入品牌片尾。单位是合成秒数；改变过渡不会改变圆环旋转速度。滑杆不会自动延长合成或素材图层，时间轴上的段落标记仅供参考。详细说明见 [docs/user/ae-export.md](docs/user/ae-export.md)。已导出的旧工程需要重新生成模板。

顶部「输出 / AE 模板」有两个用途：

- **OBS 纯画面**：下载独立 HTML 或完整 OBS 输出包，支持横竖屏、1080p / 4K、透明底、角色图开关、完整显示 / 铺满裁切。包内含浏览器源场景配置和本地路径准备脚本；OBS 直接加载页面本体，没有地址栏和编辑面板。OBS 的基础画布应与输出尺寸一致。详见 `docs/user/obs.md`。

1080p 与 4K 共用同一套排版。选择 4K 只提高输出分辨率，文字、标识、圆环、阴影与边框的画面占比一致；网页 / OBS 输出和 AE 模板均适用。旧导出文件请用新版工作台重新导出。

信息边框从片头至片尾持续显示。AE 主合成中，每侧边框有独立的 `background` 底板形状与 `text` 文字图层；双击文字图层，编辑 `Border copy · EDIT THIS`，滚动副本会自动同步。
- **AE 可编辑模板**：生成并下载 ZIP，在 AE 运行包内 IMPORT_TO_AE.jsx，创建可编辑文字、切形、圆环路径、图案及滚动边框，最后另存为 .aep。复杂质感会简化，图标与二维码等为独立图片素材，缺少的桌面字体需安装或替换。详见 `docs/user/ae-export.md`。

输出文件保留导出时的设计与图片快照。修改设计后重新导出。OBS 输出快捷键：空格暂停 / 继续、R 重播片头、S 跳至展示、E 进入已启用的片尾（先打开 OBS 源交互）。

0.8.4 已修复 AE 圆环旋转时的异常膨胀 / 收缩。旧的 AE 模板需要重新导出、重新导入；路径与描边仍可编辑，原有片头尺寸过渡保留。运动复杂的模板会产生更多关键帧，生成和导入可能稍久。

0.8.5 修复「斜切宣言」中倾斜名字底板遮挡中文短句的问题。短句间距会计入底板、投影和文字动效，竖屏及上下互换使用更紧凑的标题高度；英文短句随中文短句避让。网页输出与新导出的 AE 模板均使用修正后的排版，已有模板需重新导出。

## 交给开发者

把**整个文件夹**交给对方即可。已经生成的 `index.html` 可以预览，`src/` 中保留分模块源码。建议同时告知正在使用的方案和所需调整，并附上素材原文件。

开发流程：

```text
修改 src/ 中的对应文件
node tools/build.mjs
node tools/check.mjs
node tools/server.mjs
```

无需 `npm install`。`npm run build` 和 `npm start` 也可使用。

构建会重新生成根目录 `index.html` 与 `dist/`。**不要只修改生成后的页面**，否则下一次构建会覆盖修改。要移到其他静态托管平台，可使用 `dist/index.html`；部署动作不在本地包内自动执行。

## 当前边界

这是设计预览、参数调节及导出工具。AE 原生 .aep 由本机 After Effects 运行生成脚本后保存；复杂网页质感不保证逐像素还原。编辑器中的上传素材尚未持久化，交接仍需附带原始素材。适配标识是展示内容，选择它们不会替模型自动完成对应适配。

独立页面保留沙盒 iframe 与 CSP。项目不包含云端部署凭据、API 密钥或账号资料。
