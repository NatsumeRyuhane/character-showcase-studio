# Manual After Effects harnesses

These scripts run inside Adobe After Effects (ExtendScript, ES3). `node tools/check.mjs` does **not** run them, and nothing in the build depends on them. They are kept to repeat native AE checks by hand after changes to the AE export (`src/ae-export.js`, `runtime/ae-import-template.jsx`, `runtime/export-packages.js`).

Run a script from AE with **File → Scripts → Run Script File…**. Each one writes its result as a text file next to itself and then quits AE, so run it in a separate AE instance, not one with unsaved work.

## `post-fx/`: post-processing export check

| File | Role |
| --- | --- |
| `none.jsx`, `polar.jsx`, `crt.jsx`, `holo.jsx`, `bloom.jsx`, `anamorphic.jsx`, `prism.jsx`, `film.jsx` | AE import scripts generated by the studio, one per post-processing effect. They are snapshots taken when post-processing was added (0.10.x), not built from the current source. |
| `RUN_QA.jsx` | Imports every fixture and checks layer order (MODEL < FX OPTICS < FX ADJUSTMENT; INTRO and BORDER above the FX layers). It also evaluates every enabled expression at several times. Writes `report.txt`. |
| `CHECK_CONTROLS.jsx` | Imports `holo.jsx` and lists the effects on the `CONTROLS` layer. Writes `controls.txt`. |
| `report.txt`, `controls.txt` | Results from the last recorded run. |

To check the current source, export fresh AE packages from the studio, replace the fixture scripts with each package's `IMPORT_TO_AE.jsx` (keep the effect names as file names), and run `RUN_QA.jsx` again.

## `effect-query/`: AE built-in effect properties

`ae-query-post.jsx` lists the property indices and match names of the Glow, Gaussian Blur and Noise effects in the local AE install. It writes `ae-post-properties.txt`. The recorded output comes from a Chinese-language AE 2026, so the display names are in Chinese. The export code must use match names, never display names.
